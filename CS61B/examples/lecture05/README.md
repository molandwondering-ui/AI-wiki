# 复制了一排位置，为什么里面的对象还会一起变

程序会显示两份不同数组中的小盒子都变成 9；随后替换其中一份数组的盒子，另一份仍是 9。最后打印每行长度不同的二维数组。

[查看完整代码](ArrayCopyDemo.java) · [返回本讲笔记](../../notes/Lecture05_双向链表泛型与数组.md) · [首次运行说明](../README.md)

## 运行

在 CS61B 目录运行：

```sh
java examples/lecture05/ArrayCopyDemo.java
```

预期输出：

```text
修改盒子：9 / 9
换个盒子：9 / 7
第一行还没创建：true
不等长的两行：[[1], [2, 3]]
```

## 按这个顺序读代码

`arraycopy` 复制的是数组格子里的值。这里格子装的是 Box 的引用，所以复制后仍共享盒子，这叫浅拷贝。`new Box(7)` 才创建了新盒子。二维数组同样是引用关系：外层每个位置指向一行，行可以分别创建、长度不同。

## 改一处试试

在 `copy[0] = new Box(7)` 后，再写 `copy[0].value = 5`。original 还会跟着变吗？
