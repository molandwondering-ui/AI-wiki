# 比较两只狗：点号前面有没有当前对象

同一件事写成两种调用：Dog.heavier(a,b) 和 a.heavier(b)。两次都找到体重 20 的大狗，而且返回的是已有对象。

[查看完整代码](DogDemo.java) · [返回本讲笔记](../../notes/Lecture02_类实例与交互式调试.md) · [首次运行说明](../README.md)

## 运行

在 CS61B 目录运行：

```sh
java examples/lecture02/DogDemo.java
```

预期输出：

```text
类方法选中：20
实例方法选中：20
返回原来的 big：true
```

## 按这个顺序读代码

第一种写法没有自动附带一只狗，因此接收 a、b 两个参数。第二种已经用 `small.` 指明当前对象，只接收另一只狗。`条件 ? a : b` 表示条件成立选 a，否则选 b；`==` 在这里检查是不是同一只对象。

## 改一处试试

把 small 的体重改成 30，预测三行输出。再把两只狗都改成 20，观察代码约定平局时返回哪一只。
