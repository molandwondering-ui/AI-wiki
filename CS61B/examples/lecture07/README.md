# 亲眼看见元素数量和容量分别怎么变

开始只有两个空位，添加第 3 个数时容量变成 4，但 size 只变成 3。删掉末尾后，再访问这个下标会被拒绝。

[查看完整代码](ResizableListDemo.java) · [返回本讲笔记](../../notes/Lecture07_数组列表扩容与内存保留.md) · [首次运行说明](../README.md)

## 运行

在 CS61B 目录运行：

```sh
java examples/lecture07/ResizableListDemo.java
```

预期输出：

```text
size=1，容量=2
size=2，容量=2
扩容到：4
size=3，容量=4
第二个数：20
删除末尾：30
读取被拒绝：下标 2，size=2
空列表不能删除
```

## 按这个顺序读代码

`Arrays.copyOf` 新建数组并复制旧内容，赋值后 items 才指向更大的数组。size 只统计用户添加的有效元素。`try/catch` 让例子展示越界和空表删除的报错后还能继续运行，并不是把这些操作变成合法操作。这里为便于观察打印扩容信息，只演示整数列表，不含缩容。
