- 来源：[tsingyuec/cs336-blog/transcripts](https://github.com/tsingyuec/cs336-blog/tree/e966bb4c04d05b76d08db954da55cf4a51bd7a63/transcripts)
- 导入版本：`e966bb4c04d05b76d08db954da55cf4a51bd7a63`
- 原视频：[Stanford CS336 中文配音合集](https://www.bilibili.com/video/BV11LEA6eEuj/)

这里保留来源文件的原有名称和字幕内容，仅将相对图片路径改为固定版本的在线链接。仓库现有的 [`subtitles/`](../subtitles/) 是另一套覆盖 35 集的清洗字幕；[`notes/`](../notes/) 是整理后的学习笔记。
