# 3-8：数组访问，就是按元素大小计算地址

## 核心结论

- 一维数组元素的地址是“起始地址 + 索引 × 元素大小”。指针加一，也按这个大小前进。
- C 的二维数组是“数组里面再放数组”，按行连续存储；它和 `int **` 不是同一种布局。
- 编译器可以把重复的下标计算改成地址与固定步长更新，读汇编时应先认清每个地址代表什么。

## 1. 数组下标先决定地址，再读取内容

视频分别展示 `char A[8]` 与 `int B[4]`。在 `char` 占 1 字节、`int` 占 4 字节的课堂环境中：

| 对象 | 总大小 | 索引为 i 的元素地址 |
|---|---:|---|
| `char A[8]` | 8 字节 | `X_A + i` |
| `int B[4]` | 16 字节 | `X_B + 4*i` |

![课堂画面：数组下标先决定地址，再读取内容](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00030.jpg)

[回看画面 00:30](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=30)

`X_A`、`X_B` 表示数组起始地址。数组本身不需要为每个元素再存一份“地址表”，编译器知道元素大小，就能算出位置。

地址和值是两件事：`&E[2]` 是索引 2 的元素放在哪里，`E[2]` 是那里存了什么。索引从 0 开始，所以索引 2 是第三个元素。

```c
&E[2] == E + 2       // 两边表示同一元素的地址
E[2]  == *(E + 2)    // 两边读取同一元素的值
```

这里 `*` 是解引用，即访问指针指向的对象。上面用于说明对应关系，假定索引有效。

## 2. 指针加一，表示走过一个元素

假设示意图里的 `char *p` 与 `int *q` 都指向地址 `0x100`，则 `p+1` 对应 `0x101`，`q+1` 对应 `0x104`。这不是指针规则前后不一致，而是两个指针所指向的类型大小不同。

![课堂画面：指针加一，表示走过一个元素](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00076.jpg)

[回看画面 01:16](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=76)

可以把它理解为“向前走一格”：格子是字符，就跨一个字节；格子是四字节整数，就跨四个字节。实际程序中的指针运算应限制在同一数组及允许的尾后一位置，尾后一位置只能比较或计算，不能解引用。

[回看指针与数组取值：01:33](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=93)

## 3. 二维数组先跨行，再在行内找列

`int A[5][3]` 的外层有 5 个元素，每个元素又是含 3 个整数的数组。存储顺序是：

```text
A[0][0] A[0][1] A[0][2]  A[1][0] A[1][1] A[1][2]  ...
          第 0 行                    第 1 行
```

![课堂画面：二维数组先跨行，再在行内找列](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00218.jpg)

[回看画面 03:38](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=218)

这种布局叫**行优先**。对一般形式 `T D[R][C]`，每个元素大小为 L：

$$
\operatorname{addr}(D[i][j])=X_D+L(Ci+j)
$$

`Ci` 是前 i 行共有多少个元素，`+j` 是行内偏移，最后乘 L 把“元素个数”换成字节数。对于 `int A[5][3]`，公式成为 `X_A + 4*(3*i+j)`。

补充例子：`A[2][1]` 前面有 `2*3+1=7` 个整数，因此距数组起点 28 字节。

**二维数组不是指针的数组。**连续的 `int A[5][3]` 不需要先读取一个行指针；`int **` 则涉及不同的类型和访问结构，不能仅因为都写了两层下标就互相替代。

## 4. 汇编把下标公式拆成几步地址运算

假设 `%rdi` 保存数组基址，`%rsi` 保存 i，`%rdx` 保存 j，下面是与课堂公式等价的示意：

```asm
leaq (%rsi,%rsi,2), %rax    # 3*i
leaq (%rdi,%rax,4), %rax    # X_A + 12*i
movl (%rax,%rdx,4), %eax    # 读取 X_A + 12*i + 4*j 处的 int
```

![课堂画面：汇编把下标公式拆成几步地址运算](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00273.jpg)

[回看画面 04:33](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=273)

前两条 `lea` 只计算数值，不读取内存；最后的 `movl` 才读取数组元素。把地址计算和数据读取分开，是理解这段代码的关键。

## 5. 固定维度让循环可以直接更新地址

视频使用 `N=16` 的矩阵，计算 A 的第 i 行与 B 的第 k 列的内积：

$$
\text{result}=\sum_{j=0}^{N-1}A[i][j]B[j][k]
$$

![课堂画面：固定维度让循环可以直接更新地址](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00326.jpg)

[回看画面 05:26](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=326)

直观写法每轮用下标找元素。编译器则可以预先算好行首、列首与终点，循环中只做三件事：取两个数、相乘累加、更新地址。

| 每轮移动 | 字节步长 | 原因 |
|---|---:|---|
| A 的行内下一个元素 | 4 | 相邻 int 连续排列 |
| B 的列内下一个元素 | 64 | 跨过一整行：16 × 4 |

![课堂画面：固定维度让循环可以直接更新地址](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00458.jpg)

[回看画面 07:38](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=458)

最后用地址比较判断循环是否结束。不要被寄存器名字淹没：先把它们标成“当前 A 元素”“当前 B 元素”“终点”“累计值”，循环就容易读了。

这里讲的是机器级地址更新。C 源码可以保留清楚的 `for (j=0; j<N; ++j)`，由编译器生成适当实现；不需要手写可能越过数组边界的终点指针来追求同样外观。

## 6. 变长数组只把行宽推迟到运行时决定

C99 引入变长数组。视频展示的参数形式可概括为：

```c
int get_element(int n, int A[n][n], int i, int j)
{
    return A[i][j];
}
```

这是按课堂思路整理的最小接口示例，假设 n 为正且下标有效。原画面参数名写作 k、函数体却使用 j，这里统一为 j；是否支持这类声明需看编译器与所选 C 标准。n 出现在 A 前面，是因为 A 的类型声明需要用到它。

![课堂画面：变长数组只把行宽推迟到运行时决定](https://github.com/molandwondering-ui/AI-wiki/releases/download/csapp-through-3-10-images/BV1ho4y1d7J6_00515.jpg)

[回看画面 08:35](https://www.bilibili.com/video/BV1ho4y1d7J6/?t=515)

地址仍为 `X_A + sizeof(int)*(n*i+j)`。区别是 n 不再是编译时常量，机器代码需要按运行时的行宽计算。矩阵内积的 C 循环可以几乎不变，编译器却会选择不同的地址计算方式。

## 自测

`int A[5][3]` 中，`A[1][2]` 到 `A[2][0]` 相隔几个 int？

<details><summary>查看答案</summary>

相隔一个。前者是第 1 行最后一个元素，后者紧接着是第 2 行第一个元素。按公式，元素偏移分别为 5 和 6；四字节 int 环境中相隔 4 字节。

## 术语速查

| 术语 | 含义 |
|---|---|
| 解引用 | 访问指针所指的对象 |
| 行优先 | 每一行的元素先连续存完，再存下一行 |
| 步长 | 相邻两次访问地址之间的差值 |
| VLA | 维度可以在运行时确定的变长数组 |
