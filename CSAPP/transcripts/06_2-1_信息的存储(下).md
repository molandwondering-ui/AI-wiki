## 00:00–00:46

上一讲讨论了十六进制与字节存储，本讲继续研究信息存储。C 字符串是以空字符 NUL（\0）结尾的字符数组。例如 "abcde" 含 5 个可见字符，字符串长度为 5，但连同结尾空字符需要 6 字节存储。用上一讲的字节打印程序可看到各字符的编码，末尾字节是 0x00。采用相同 ASCII 编码的系统会得到相同的字符字节，因此这种文本表示比依赖机器布局的二进制数据更容易跨平台。

## 00:46–01:36

二进制是计算机编码、存储和操作信息的基础。乔治·布尔将逻辑真假对应到 1 和 0，建立布尔代数。非（NOT）把 0 变为 1、把 1 变为 0；与（AND）只有在两个输入都为 1 时才得到 1，只要有一个为 0，结果就是 0。

## 01:36–02:34

或（OR）只有在两个输入都为 0 时结果为 0，其他情况为 1。异或（XOR）在输入相同时为 0、不同时为 1。C 支持按位布尔运算：将十六进制展开为二进制，逐位运算，再转回十六进制。视频用 8 位位向量说明：00000000 逐位取反是 11111111，即 0xFF。这是 8 位示意；真正的 C 表达式还要考虑整数提升后的类型宽度。

## 02:34–03:19

位运算常用于掩码，即保留或筛选指定的位。对 0x89ABCDEF 与 0xFF 做按位与，保留最低有效字节，得到 0x000000EF。除按位运算外，C 还有逻辑运算；要分清两套运算符。逻辑运算把任何非零值视为真，把 0 视为假。

## 03:19–04:10

逻辑运算的结果只有 0 或 1，按位运算通常不受这个范围限制。表达式 a && 5/a 具有短路行为：a 为 0 时，左侧已是假，不再计算 5/a，因此避免了除以 0。左移则将高端移出的位丢弃，低端补 0；视频以 8 位位向量 01100011 的左移一位、两位展示过程。对实际 C 移位表达式，移位量必须非负且小于提升后左操作数的位宽，不能取等于位宽的值。

## 04:10–05:07

右移分逻辑右移和算术右移。逻辑右移丢弃低端位，在左端补 0。算术右移在左端复制原最高位：原最高位为 0 时补 0，与逻辑右移相同；原最高位为 1 时补 1。视频比较最高位为 0 的 value1 与最高位为 1 的 value2，后者最能显示两种右移的区别。
